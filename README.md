# AI Research Assistant

An AI-powered research assistant built with **LangChain, LangGraph, and FastAPI**, designed to help users analyze research documents and receive context-aware, source-grounded answers.

### Key Features
- **Advanced RAG Pipelines:** Document ingestion, chunking, embedding, and retrieval to generate context-aware responses grounded in source documents.
- **Agentic Workflows:** LangGraph-powered stateful workflows with conditional routing, self-correction, and controlled execution.
- **Security & Guardrails:** Protection against prompt injection, personally identifiable information (PII) leakage, and unsafe or manipulated LLM outputs.
- **LLM Guardrails:** Input validation and output checks to improve response safety and reliability.
- **Caching & Performance:** Response caching to reduce redundant LLM calls, improve latency, and optimize API usage.
- **REST API:** FastAPI endpoints for document processing and AI-powered question answering.
- **Deployment:** Containerized application deployed on Render.

### Tech Stack
**Python · FastAPI · LangChain · LangGraph · RAG · LLM Guardrails · PII Protection · Response Caching · Docker · Render**
